# AFGlion Admin Panel Plan

Admin access is tied to an approved Telegram ID after trusted Telegram identity verification.

## Dashboard
- Total users
- Total wallet balance
- Pending deposits
- Pending withdrawals
- Active VIP subscriptions
- VIP package sales
- Referral payouts

## Users
- Search by Telegram ID / username
- View wallet and activity
- Manual credit / debit
- Ban / unban

## VIP Packages
- Create
- Edit
- Enable / disable
- Configure name, price, daily reward, duration and badge

## Deposits
- Review pending proof / TXID
- Approve and credit wallet
- Reject with reason

## Withdrawals
- Review requests
- Approve as paid
- Reject and preserve/refund balance according to final transaction design

## Referrals
- Referral reward settings
- Review inviter/invitee records
- Referral payout history

## Settings
- Deposit methods
- Payment instructions
- Maintenance mode
- Support links
